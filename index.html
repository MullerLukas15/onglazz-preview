Pro IT

    
Jak to dostat na onglazz.cz

    
    
      
  1. Načíst widget jednou pro celý web, např. v head.script v nuxt.config.js. Šablony si widget načte sám.
    2. 
    


<script src="https://preview.onglazz.cz/widget.js" defer></script>

    
    
      
  1. Vložit prázdný kontejner do galerie každého produktu, přes hlavní fotku. Widget podle adresy produktu najde šablonu. Produkt bez šablony nechá kontejner skrytý.
    2. 
    


<div data-onglazz-preview></div>

    
    
      
  1. Klíče polí vypsat k inputům konfigurace, aby widget nezávisel na textech v adminu:
    2. 
    


<input data-config-key="vinylova-deska-skladba-text-1-CZ" …>

    
    
      
  1. Před přidáním do košíku zavolat export a obrázky uložit k objednávce jako u skleněných desek:
    2. 
    


const p = OnglazzPreview.instances[0];
if (p) {
  const { preview, photo, crop, texts } = await p.exportForOrder();
  // preview a photo jsou JPG (Blob), crop a texts jdou uložit jako JSON
}
